# Thiết kế thí nghiệm

Chỉ lưu kế hoạch và cấu hình nhỏ có thể tái lập, tham chiếu dataset version,
split ID, preprocessing ID và run IDs. Chưa có thí nghiệm được thực hiện.

Outputs thật đặt trong artifacts/runs, không copy dataset/model vào thư mục này
hoặc thư mục task. Không thêm bảng scores giả để minh họa kết quả.
